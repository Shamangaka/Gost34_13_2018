# Кандидат на исследовательский релиз Qalqan — v22

**Статус:** финальные технические испытания v22 завершены 31.10.2026: 19/19 PASS.
Документ относится к исследовательскому релизу, не подтверждающему криптографическую стойкость, constant-time или сертификацию.

## Охват

Исходники, тесты и документация блочного примитива Qalqan СТ РК 4009-2025
в Rust, C++20 и Go. Другие языковые реализации в этот аудит не включены.

## История уже проведённых изменений

- Rust v8: экспериментальный S-box на фиксированных операциях с известным
  компромиссом по производительности; не объявляется доказанным CT.
- Rust v13: opt-in `ctr_no_wrap`, проверка диапазона счётчика до записи.
- Rust v19: удаление неиспользуемых зависимостей, обновление lock-файла,
  `cargo audit` в пользовательском окружении без обнаруженных advisory.
- C++ v20: bounds-checked публичный API и проверки некорректных параметров;
  GCC/Clang по 9 тестов ASan+UBSan PASS на машине пользователя.
- Go v21: запрет использования после `Reset`, проверка ошибок тестового
  Kexp, права 0600, 155 прямых проверок рабочего расписания ключа;
  `go test`, `go vet`, `go test -race` PASS на машине пользователя.

## Открытые ограничения, не исправляемые в этом релизе

- C++/Go не constant-time из-за табличных подстановок.
- Rust v8 не прошёл формальную CT/taint-проверку на целевых архитектурах.
- Отсутствуют аутентифицированные режимы и автономное управление IV/nonce.
- Результаты функционального соответствия ограничены доступными тестовыми
  векторами и принятыми неофициальными интерпретациями стандарта.
- Низкоуровневый C++ внутренний API остаётся потенциально небезопасным
  при нарушении предусловий о размерах буферов.
- Возможные остатки ключевого материала в памяти; обнуление best-effort.
- Код и CI прочих языков могут отличаться от протестированного объёма.

Все записи о тестах должны ссылаться на `status.tsv`, логи, хеши источников,
версии компиляторов и исходную ревизию Git. Не публикуйте обобщение PASS
до выполнения `v22` и проверки логов. Никаких автоматических коммитов.
